# LumaHome Repository Instructions

- Work in small, reviewable increments.
- Do not implement beyond the requested step.
- Prefer simple solutions over abstractions.
- Preserve Local-First behavior: the device must remain useful without the backend or network.
- Keep the dashboard framework-free: plain HTML, CSS, and vanilla JavaScript only.
- Run formatting, linting, and tests after Rust changes.
- Report changed files and validation commands.
- Never add a simulator unless explicitly requested.
